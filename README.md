## Skills 列表

### 🎓 [beginner-tutor](./beginner-tutor/SKILL.md)

**用途**：通用入门教学 Skill，通过结构化对话将任意复杂领域的知识教给完全的新手，最终生成一份可存档、可分享的精美教程文档。

**适用场景**：

- 用户对某个领域完全陌生，需要从零开始学习（金融、工程、医学、法律、编程等任意学科）
- 用户需要快速了解一个新领域以便在工作中使用
- 用户想制作一份面向初学者的教程、讲解文档或学习指南
- 用户说"我不懂 X"、"帮我学一下 Y"、"我需要快速上手 Z"

**核心工作流（五阶段）**：

1. **Intake（摸底）**：了解学习者的目标、背景和需求，确定教学角度与深度
2. **Teach（教学对话）**：逐概念讲解，每个概念按"锚点 → 直觉 → 举例 → 定义 → 检验 → 过渡"循环推进，不讲超过几段不停下来确认理解
3. **Consolidate（巩固）**：绘制概念关系图，让学习者用自己的话复述核心内容，排查常见误区
4. **Document（生成文档）**：在理解已建立后，输出结构统一的入门教程文档（含前言、各章节直觉讲解 + 具体例子 + 常见误区、概念总图、术语速查表）
5. **Iterate（迭代）**：根据反馈修订文档，调整类比方式或补充章节

**核心原则**：理解先于文档——文档是真实理解的记录，而非替代品。

**输入**：用户说明想学的主题（可以很模糊，如"帮我学一下期权"）

**输出**：对话过程中的逐步讲解 + 最终的 Markdown 入门教程文档

**触发关键词**：帮我学、我想了解、我不懂、从零开始、入门教程、帮我理解、快速上手、teach me、explain X to me、beginner guide

## 如何安装 Skill

1. 下载对应 Skill 文件夹
2. 在 Claude 中上传安装，或将文件夹路径挂载到 `/mnt/skills/user/` 目录下
3. 在对话中使用触发关键词即可自动调用

## 贡献新 Skill

如需添加新 Skill，请按以下结构新建文件夹：

```
your-skill-name/
└── SKILL.md          ← 必须，包含 YAML frontmatter 和 Skill 正文
```

并在本 README 的"Skills 列表"中补充对应条目。
